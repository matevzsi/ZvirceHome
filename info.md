# Zvirce SmartHome (PoLED) Integration

Control your Zvirce SmartHome PoLED gateway devices directly from Home Assistant!

## Features

**Full Light Control**
- RGBW color lights
- Color temperature adjustment
- Brightness control
- Simple on/off switches

**Smart Cover Control**
- Position control (0-100%)
- Tilt angle adjustment
- Stop command support

**Easy Configuration**
- User-friendly setup through Home Assistant UI
- No YAML configuration needed
- Customize channel names
- Enable/disable individual channels

**Local Control**
- Direct communication with your gateway
- No cloud dependency
- Fast response times
- Polls every 2 seconds for updates

## Quick Start

1. **Install** the integration through HACS
2. **Restart** Home Assistant
3. **Add Integration**: Go to Settings → Devices & Services → Add Integration
4. **Search** for "Zvirce SmartHome"
5. **Configure**: Enter your PoLED gateway IP address and user ID
6. **Done!** All your lights and covers will be automatically discovered

## Configuration

After installation, you can customize your setup:

- **Configure Lights**: Enable/disable channels and set custom names
- **Configure Covers**: Enable/disable channels and set custom names

Access these options by clicking "Configure" on the integration card in Settings → Devices & Services.
